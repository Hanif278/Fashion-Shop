# Fashion Shop POS — GitHub → Vercel + Google Sheets

## ফোল্ডার
- `index.html` — আপনার সফটওয়্যার (ডিজাইন অপরিবর্তিত) + রোল কন্ট্রোল + 80mm রিসিপ্ট
- `api/gas.js` — Vercel থেকে Apps Script-এ নিরাপদ সংযোগ
- `Code.gs` — Apps Script কোড (পুরোনো Code.gs-এর জায়গায় বসবে)
- `vercel.json`, `package.json`, `.gitignore`

## ধাপ ১: Google Apps Script
1. আপনার Google Sheet খুলুন → Extensions → Apps Script (শিটের সাথে যুক্ত স্ক্রিপ্টই ব্যবহার করুন)।
2. পুরোনো `Code.gs` মুছে এই `Code.gs` বসান। `Index` HTML ফাইলের আর দরকার নেই।
3. Project Settings → Script properties → `API_SECRET` নামে একটি লম্বা র‍্যান্ডম টেক্সট দিন (যেমন ৪০ অক্ষর)।
4. Deploy → New deployment → Web app → Execute as: **Me**, Who has access: **Anyone** → Deploy। প্রথমবার Authorize করুন।
5. যে Web app URL পাবেন (`.../exec`) সেটি কপি করুন।
6. একবার Run করুন: `setupShopSheets` (শিট ট্যাব তৈরি হবে)।

## ধাপ ২: GitHub
এই ফোল্ডারের সব ফাইল নতুন রিপোজিটরির রুটে push করুন (`index.html` রুটে থাকবে, `api/` ফোল্ডারসহ)।

## ধাপ ৩: Vercel
1. Vercel → Add New Project → GitHub রিপোজিটরি Import (Framework: Other)।
2. Settings → Environment Variables:
   - `GAS_URL` = ধাপ ১-এর `/exec` URL
   - `GAS_SECRET` = ধাপ ১-এর `API_SECRET` (হুবহু একই)
3. Deploy। এরপর যেকোনো ডিভাইসে Vercel লিংক খুলে লগইন করুন।

## রোল (সার্ভারেও কার্যকর, শুধু স্ক্রিনে লুকানো নয়)
| রোল (ইউজার ম্যানেজমেন্টে) | কী করতে পারে |
|---|---|
| admin | সবকিছু, সেটিংস ও ইউজার ম্যানেজমেন্ট সহ |
| manager | সবকিছু, শুধু সেটিংস ও ইউজার ম্যানেজমেন্ট ছাড়া |
| cashier (সেলসম্যান) | শুধু সেলস/ক্যাশ মেমো; আজকের ও মাসিক বিক্রি, বাকি দেখে; মাসিক লাভ ও খরচ দেখে না |
| stock | শুধু প্রোডাক্ট/স্টক এন্ট্রি |

পুরোনো `inventory` ইউজারের রোল এখন `manager`। স্টক ইউজার বানাতে অ্যাডমিন হিসেবে ইউজার ম্যানেজমেন্টে তার রোল **Stock** করুন।
ডিফল্ট পাসওয়ার্ড (`admin1234`, `user1234`) প্রথম দিনেই বদলান।

## ডাটা নিরাপত্তা ও সিঙ্ক
- সেভ এখন শিট `clear()` করে না। আইডি মিলিয়ে বদলায় বা নতুন সারি যোগ করে।
- শুধু আপনি ডিলিট চাপলে শিট থেকে সারি মোছা হয়।
- পুরোনো ডেমো-ডাটা অটো-ক্লিনআপ বন্ধ করা হয়েছে (আসল ডাটা মুছে যেতে পারত)।
- প্রতি ৬ সেকেন্ডে অন্য ডিভাইসের পরিবর্তন চেক হয়; কেউ ফর্ম খুলে থাকলে তখন রিফ্রেশ হয় না।

## 80mm রিসিপ্ট
ইনভয়েস প্রিভিউয়ের প্রিন্ট বাটন এখন `@page 80mm` ব্যবহার করে। প্রিন্ট ডায়ালগে প্রিন্টার **OPS (80mm)** বেছে নিন, Margins: None, Scale: 100%।
